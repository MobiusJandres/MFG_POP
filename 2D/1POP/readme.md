# 2D Mean Field Game (MFG) PDE Crowd Solver

A solver for **2D Continuous Mean Field Games (MFG)** applied to macroscopic crowd motion and multi-agent spatial pathfinding. 

This repository translates benchmark discrete grid maps and agent scenarios from the **MovingAI Benchmark** repository into continuous spatial Partial Differential Equations (PDEs). It solves the coupled system of **Hamilton-Jacobi-Bellman (HJB)** and **Fokker-Planck (FP)** equations using **Numba-accelerated finite-difference schemes**, sparse matrix operators, Newton-Raphson linearization, and damped Picard iteration.

## Overview

Mean Field Games (MFG) model the asymptotic behavior of large populations of interacting, rational agents. Rather than tracking thousands of individual trajectories independently, MFG formulates crowd movement as a macroscopic coupled system of two PDEs:
1. **Backward in time (HJB):** Determines the optimal pathfinding value function $u(t, x, y)$ for agents considering distance to goals and localized crowd congestion.
2. **Forward in time (FP):** Tracks the spatial evolution of the crowd density distribution $m(t, x, y)$ driven by the optimal drift field generated by $u$.

This script allows direct importing of standard benchmark maps (`.map`) and scenario files (`.scen`) from [MovingAI](https://movingai.com/benchmarks/) into a continuous domain with arbitrary spatial resolution ($N_x \times N_y$).

## Mathematical Formulation

### 1. Hamilton-Jacobi-Bellman (HJB) Equation
The value function $u(t, x, y)$ represents the dynamic cost-to-go for agents and satisfies the backward PDE:

$$\partial_t U + \nu \Delta U + H(M, \nabla U) - f(x, y) = 0$$

Where:
- $\nu = 0.05$ is the diffusion constant modeling individual Brownian stochastic motion / drift uncertainty.
- $H(m, \nabla u) = -8 \left(1 + M\right)^{-0.75} |\nabla U|^2 + 0.1$ is the non-linear Hamiltonian incorporating congestion penalization $c_h(M) = 16 (1+M)^{-0.75}$.
- Terminal condition at time $T$: $U(T, x, y) = g(x, y) = -\text{scale} \cdot d_{\text{goal}}(x, y)^2$.

### 2. Fokker-Planck (FP) Continuity Equation
The crowd density distribution $m(t, x, y)$ obeys the forward conservation law:

$$\partial_t m - \nu \Delta m - \nabla \cdot \left( m \cdot c_h(m) \nabla u \right) = 0$$

- Initial condition at time $t=0$: $m(0, x, y) = m_0(x, y)$ constructed as a Gaussian mixture centered at agent starting coordinates.
- Neumann boundary conditions: Reflective zero-flux boundary conditions along outer borders and around interior map obstacles.

### 3. Damped Picard System Coupling
Because $u$ is solved backward from $T \to 0$ and $m$ is solved forward from $0 \to T$, the system is solved via a fixed-point Picard iteration with relaxation parameter $\theta \in (0, 1]$:

$$u^{(k+1)} = \theta u_{\text{solve}}(m^{(k)}) + (1-\theta) u^{(k)}$$
$$m^{(k+1)} = \theta m_{\text{solve}}(u^{(k+1)}) + (1-\theta) m^{(k)}$$

## Key Components & Classes

### `MAP2PDE`
Translates discrete MovingAI `.map` grid representations into continuous spatial meshes $(X, Y)$ and initial/terminal conditions.
- `parse_files(num_agents)`: Reads obstacle characters (`.`, `G`, `@`, `O`) and parses agent start/goal positions.
- `get_pde_obstacle_mask()`: Projects continuous grid cells to discrete map cells to form binary obstacle masks (`0` for wall/obstacle, `1` for navigable space).
- `build_initial_density()`: Sums Gaussian distributions centered at agent start coordinates to compute initial continuous density $m_0(x, y)$.
- `build_terminal_cost()`: Generates terminal cost penalty landscape based on distance to closest agent goal.

### `MFGSolver`
Manages the coupled forward-backward PDE system across time horizon $T$ divided into $N_t$ intervals.
- `solve_forward_FP()`: Computes forward density evolution $M$ using upwind discretizations and sparse linear solves (`spsolve`).
- `solve_backward_HJB()`: Solves HJB backward in time step-by-step using a Newton-Raphson nonlinear iteration scheme (`get_u_onestep_newton`).
- `run_picard_system(max_iters, tolerance)`: Executes damped Picard iteration loop until space-time $L^2$ norm residuals drop below `tolerance`.

### `MFGPlotter`
Provides visualization tools tailored for spatial MFG dynamics.
- `plot_snapshots()`: Displays a 2x2 grid featuring:
  - Initial Density $M(t=0)$
  - Midpoint Density $M(t=T/2)$
  - Final Density $M(t=T)$
  - Value Function / Pathfinding landscape $U(t=0)$
- `save_density_frames(output_dir)`: Exports high-resolution PNG frames (`frame_000.png`, `frame_001.png`, ...) suitable for building MP4/GIF animations (You can build these from the terminal or add onto the script).
